# Цифровые носители: экспорт, форматы, соцсети, доступность

## Назначение
Правила подготовки и экспорта графики для экрана. **Размеры платформ часто меняются: всегда проверяйте актуальные требования.**

## Форматы файлов
| Формат | Тип | Когда использовать |
|---|---|---|
| SVG | вектор | логотипы, иконки, простые иллюстрации на сайте |
| PNG | растр, без потерь, прозрачность | интерфейсные элементы, скриншоты, логотипы на фоне |
| JPG | растр, с потерями | фотографии |
| WebP / AVIF | растр, современные | веб-фото и графика (проверьте поддержку) |
| GIF | анимация, 256 цветов | короткие простые анимации |
| MP4 / WebM | видео | видео и анимации |
| Lottie (JSON) | векторная анимация | интерфейсная анимация |
| PDF | документ | презентации, отчёты, вёрстка |

## Разрешение и масштабирование
- Экраны: единица измерения — пиксель; для плотных экранов выдавайте @2x и @3x или векторные файлы.
- Сжимайте изображения: компромисс «качество/вес». Для веба ориентир: фото до нескольких сотен КБ.
- Профиль: sRGB.

## Ориентиры по размерам (проверяйте актуальность)
| Носитель | Ориентир |
|---|---|
| Квадратный пост в соцсетях | 1080×1080 |
| Портретный пост | 1080×1350 (4:5) |
| Вертикальное видео/сторис/рилс | 1080×1920 (9:16) |
| Превью YouTube | 1280×720 (16:9) |
| Open Graph (превью ссылок) | 1200×630 |
| Аватар | квадрат, учтите круглую обрезку и безопасную зону |
| Favicon | 32×32, 180×180 (apple touch), 192/512 (PWA); SVG-иконка по возможности |
| Email-шапка | ширина 600–640 px |

Каждая платформа обрезает и сжимает по-своему: оставляйте безопасные зоны и тестируйте.

## Адаптивность айдентики
- Логотип: полный, компактный, знак, моно; правила переключения между ними по ширине.
- Цвет: светлая и тёмная темы; проверьте контраст и в тёмной теме.
- Типографика: масштаб размеров для мобильных и больших экранов.
- Сетка: адаптивные колонки (4 на мобильных, 8 на планшетах, 12 на десктопе: ориентир).

## Доступность
- Контраст по WCAG (см. 02_color.md).
- Альтернативный текст для значимых изображений.
- Размер интерактивных элементов: не менее 44×44 pt/px (ориентир для касания).
- Не опирайтесь только на цвет.
- Анимации: избегайте мигания; предусмотрите отключение или уменьшение движения.
- Читаемость: размер основного текста от 16 px, интерлиньяж не менее 1,4.

## Основы motion для бренда
- Движение отражает характер: быстрое и резкое (энергия), плавное (спокойствие).
- Единые кривые (easing) и длительности: 150–400 мс для интерфейсных реакций (ориентир).
- Логотип в движении: правила анимации, длительность, финальный кадр.

## Передача файлов разработчикам
- Именованные стили, компоненты, токены.
- Экспорт ресурсов: SVG для иконок, WebP/PNG для растров, шрифты с лицензией.
- Спецификация: отступы, размеры, состояния (наведение, нажатие, неактивное, ошибка).

## Типичные ошибки
- Растровый логотип на сайте вместо SVG.
- Тяжёлые изображения, медленная загрузка.
- Текст внутри картинки без альтернативы.
- Неучтённая обрезка платформами.
- Низкий контраст в тёмной теме.

## Правила для ИИ
- Называя размеры платформ, помечайте «на момент составления базы» и советуйте сверить с документацией платформы.
- Для каждого носителя предлагайте формат файла и обоснование.
- Напоминайте об адаптивных версиях логотипа и теме тёмного режима.
