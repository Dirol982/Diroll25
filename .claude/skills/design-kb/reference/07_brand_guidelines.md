# Бренд-бук и дизайн-система бренда

## Назначение
Как документировать айдентику, чтобы её могли применять другие люди без потери качества.

## Уровни документации
| Уровень | Содержание | Для кого |
|---|---|---|
| Краткий гайд (1–4 страницы) | логотип, цвета, шрифты, базовые правила | малый бизнес, стартап |
| Брендбук (20–60 страниц) | стратегия + визуал + применения | средний бизнес |
| Дизайн-система / портал бренда | компоненты, токены, шаблоны, библиотека активов | крупные компании, продукты |

## Структура брендбука
1. **Введение:** кто мы, миссия, ценности, позиционирование, личность.
2. **Голос и тон:** принципы, примеры «так/не так», словарь слов-маркеров.
3. **Логотип:** основной и варианты, охранное поле, минимальный размер, допустимые фоны, запреты.
4. **Цвет:** основные, вторичные, нейтральные, функциональные; значения во всех моделях; пропорции; доступные пары контраста.
5. **Типографика:** шрифты, иерархия, размеры, интерлиньяж, веб-аналоги, запасные шрифты.
6. **Изображения:** фото-стиль, кадрирование, цветокоррекция, примеры «так/не так»; рекомендации для иллюстраций и иконок.
7. **Графические элементы:** паттерны, формы, линии, ключевые приёмы.
8. **Сетки и композиция:** примеры макетов.
9. **Применения:** документы, цифровые носители, печать, упаковка, среда, одежда.
10. **Движение (при необходимости):** принципы анимации, тайминги.
11. **Доступ к файлам:** ссылки, структура папок, контакты ответственного.

## Что делает руководство полезным
- Правила объясняют **«почему»**, а не только «как».
- Много реальных примеров, а не только схем.
- Показаны **ошибки** («нельзя»): искажение, смена цвета, эффекты, плохой фон.
- Указаны **значения**: размеры, процентные отступы, HEX/RGB/CMYK, названия стилей.
- Лёгко находить: оглавление, нумерация, поиск.
- Есть **чёткий владелец** и дата версии.

## Дизайн-токены (для цифровых продуктов)
Имена и значения решений: цвета, отступы, радиусы, тени, размеры шрифта. Пример имён: `color-brand-primary`, `space-4`, `radius-md`. Токены связывают бренд и интерфейс, их используют дизайнеры и разработчики.

## Структура папок файлов (пример)
```
brand/
  01_logo/ (svg, pdf, png; color, mono, reverse)
  02_colors/ (палитры ase, aco, css)
  03_fonts/ (файлы или ссылки + лицензии)
  04_templates/ (визитки, письма, презентации, соцсети)
  05_imagery/ (фото, иллюстрации, иконки)
  06_guidelines/ (pdf, исходники)
```
Именование файлов: `бренд_тип_вариант_цвет_размер.формат`, например `acme_logo_horizontal_color.svg`. Без пробелов и спецсимволов.

## Шаблоны
Критичные для внедрения: презентация, документ (Word или Google Docs), подпись e-mail, шаблоны соцсетей, визитка, бланк, счёт. Шаблон должен быть редактируемым людьми без дизайнерских навыков и защищать ключевые решения (блокировка слоёв, стили).

## Внедрение и развитие
- Обучение команды, короткие чек-листы и видео-инструкции.
- Назначение хранителя бренда.
- Регулярный аудит применений.
- Процесс обновлений: версия, список изменений, архив.

## Типичные ошибки
- Гайд только про логотип, без системы.
- PDF без исходников и шаблонов.
- Нет правил для реальных ситуаций: документы, партнёры, мелкие форматы.
- Слишком строгие или слишком расплывчатые правила.

## Правила для ИИ
- Когда просят «сделать брендбук», предложите уровень документации по масштабу клиента и сначала согласуйте структуру.
- Для каждого правила формулируйте обоснование и пример нарушения.
- Предлагайте структуру файлов и именование вместе с гайдом.
