# Подготовка макетов к печати

## Назначение
Технические требования и ориентиры для печатных носителей. Всегда сверяйте с требованиями конкретной типографии: они приоритетнее.

## Базовые параметры
| Параметр | Ориентир |
|---|---|
| Цветовая модель | CMYK (для офсета и большинства цифровых типографий); спот-цвета для Pantone |
| Разрешение растровых изображений | 300 ppi в конечном размере (крупноформатная печать: 100–150 ppi и ниже при большом расстоянии просмотра) |
| Вылеты под обрез (bleed) | обычно 3 мм со всех сторон (в США часто 0,125 дюйма) |
| Безопасная зона | 3–5 мм внутрь от линии реза для текста и логотипов |
| Шрифты | преобразованы в кривые или встроены |
| Формат файла | PDF (часто PDF/X-1a или PDF/X-4 по требованию типографии) |
| Метки реза | по требованию типографии |
| Тонкие линии | не тоньше 0,25 pt (лучше 0,5 pt); на цветном фоне делайте толще |
| Минимальный кегль | около 6–7 pt для текста; для светлого на тёмном и засечных шрифтов крупнее |

## Чёрный цвет
- **Для мелкого текста:** 100% K (только чёрный), чтобы не было несовмещения красок.
- **Для больших плашек:** «насыщенный чёрный» (rich black), например C60 M40 Y40 K100. Конкретные значения согласуйте с типографией.
- Суммарное красочное покрытие (total ink) не должно превышать лимит типографии: часто около 280–320%.

## Спот-цвета (Pantone)
Используются для фирменных цветов, металлизированных красок и когда нужна высокая точность. Дороже CMYK; расход: дополнительная печатная секция. Сверяйте с физическим веером Pantone на нужной бумаге (coated или uncoated: результат различается).

## Наложение (overprint) и треппинг
Overprint чёрного для текста полезен; для остальных цветов включается осознанно. Треппинг решают в допечатной подготовке, договоритесь с типографией.

## Бумага
- **Мелованная (глянцевая, матовая):** насыщенные цвета, резкие изображения.
- **Немелованная:** мягкий, тёплый вид, цвета тусклее.
- **Дизайнерская:** фактура, цветная; белые цвета не получаются без специальной краски.
- Плотность: визитки 300–400 г/м², листовки 115–170, плакаты 130–200, обложки 200–300 (ориентиры).
- Направление волокна влияет на сгиб и жёсткость.

## Постпечатная обработка
| Приём | Эффект | Замечания |
|---|---|---|
| Ламинация (матовая, глянцевая, soft-touch) | защита, ощущение | тёмные плашки с матовой ламинацией царапаются |
| УФ-лак (сплошной/выборочный) | блеск, акцент | требует отдельного слоя-маски |
| Тиснение фольгой | премиальный эффект | минимальная толщина линий и промежутков |
| Конгрев (рельеф) | объём | нужна матрица |
| Вырубка, биговка, фальцовка | форма и складывание | шаблон вырубки от типографии |
| Перфорация, скругление углов | функция | |
| Склейка, переплёт | брошюры, книги | шейка и поля под переплёт |

Для каждого эффекта создаётся отдельный слой или спот-цвет с чёткой пометкой.

## Стандартные форматы (мм)
- Серия A: A3 297×420; A4 210×297; A5 148×210; A6 105×148; A7 74×105.
- DL (конверт, листовка 1/3 A4): 99×210 или 100×210.
- Визитка: часто 90×50 (РФ/Европа); 85×55 (Европа); 3,5×2 дюйма (США).
- Плакат: A2 420×594; A1 594×841; A0 841×1189; также 500×700 и 700×1000.
- Конверты, блокноты, упаковка: уточняйте у производителя.

## Фальцовка и разворот
- Для многостраничных: число страниц кратно 4 (для скрепки).
- Страницы у корешка: поля увеличены.
- Разворачиваемые макеты: учитывайте «уход» сгиба и подгонку.

## Чек-лист препресса
- [ ] Размер и вылеты верны
- [ ] CMYK или заданные спот-цвета (нет случайных RGB)
- [ ] Изображения 300 ppi, нет апскейла
- [ ] Шрифты в кривых или встроены
- [ ] Чёрный текст 100% K
- [ ] Тонкие линии и мелкий текст читаются
- [ ] Суммарное покрытие в пределах лимита
- [ ] Слои вырубки, лака, фольги отдельно
- [ ] Метки реза и разметка по требованиям
- [ ] Текст проверен, нет «Lorem ipsum»
- [ ] Получено подтверждение макета или пробная печать

## Правила для ИИ
- Все значения называйте ориентирами и просите сверять с требованиями типографии.
- Не обещайте точное совпадение цвета экрана и печати: рекомендуйте цветопробу.
- Для печати с постобработкой предложите отдельную спецификацию слоёв.
