# Глоссарий (RU / EN)

## Бренд и стратегия
- **Айдентика / Brand identity:** визуальная и вербальная система бренда.
- **Бренд-платформа / Brand platform:** стратегическое основание бренда.
- **Позиционирование / Positioning:** место бренда в сознании аудитории.
- **Тон голоса / Tone of voice:** манера коммуникации.
- **Архетип / Archetype:** обобщённый образ личности бренда.
- **Ребрендинг / Rebranding:** изменение бренда.
- **Рестайлинг / Restyling:** визуальное обновление без смены стратегии.
- **Бренд-бук / Brand book (guidelines):** документ правил использования бренда.
- **Touchpoint (точка контакта):** место встречи клиента с брендом.

## Логотип и знаки
- **Логотип / Logo:** основной идентификатор.
- **Словесный знак / Wordmark:** слово, оформленное шрифтом.
- **Монограмма / Lettermark:** инициалы.
- **Эмблема / Emblem:** название внутри формы.
- **Охранное поле / Clear space:** свободная зона вокруг логотипа.
- **Негативное пространство / Negative space:** пустое пространство, образующее форму.
- **Оптическая коррекция / Optical adjustment:** подгонка форм под восприятие.

## Типографика
- **Гарнитура / Typeface:** дизайн шрифта (семейство).
- **Шрифт / Font:** файл или конкретное начертание.
- **Кегль / Point size:** размер шрифта.
- **Интерлиньяж / Leading, line-height:** расстояние между строками.
- **Трекинг / Tracking:** общий межбуквенный интервал.
- **Кернинг / Kerning:** интервал между парой букв.
- **Засечки / Serif:** небольшие элементы на концах штрихов.
- **Гротеск / Sans-serif:** шрифты без засечек.
- **Вдова и сирота / Widow and orphan:** одиночные строки абзаца в начале/конце колонки.
- **Лигатура / Ligature:** слитное начертание нескольких букв.
- **Переменный шрифт / Variable font:** шрифт с плавной настройкой параметров.

## Цвет
- **Тон / Hue:** цвет в круге.
- **Насыщенность / Saturation:** интенсивность цвета.
- **Светлота / Value, lightness:** светлый или тёмный.
- **Аддитивная модель / Additive color (RGB):** цвета образуются сложением света.
- **Субтрактивная модель / Subtractive color (CMYK):** цвета образуются вычитанием света красками.
- **Спот-цвет / Spot color:** готовая смешанная краска (Pantone).
- **Охват / Gamut:** диапазон воспроизводимых цветов.
- **Цветопроба / Proof:** пробный оттиск.

## Композиция и вёрстка
- **Иерархия / Hierarchy:** порядок важности элементов.
- **Сетка / Grid:** структура колонок и строк.
- **Поля / Margins:** отступы от края.
- **Межколонник / Gutter:** промежуток между колонками.
- **Фокальная точка / Focal point:** главная точка внимания.
- **Негатив / Whitespace:** свободное место.
- **Мастер-страница / Master page:** шаблон страницы.

## Печать
- **Вылеты / Bleed:** запас изображения за линией реза.
- **Линия реза / Trim line:** где будет обрезан лист.
- **Безопасная зона / Safe zone:** область, где важные элементы не будут срезаны.
- **Растр / Raster:** изображение из пикселей.
- **Вектор / Vector:** изображение из математически заданных контуров.
- **DPI/PPI:** точек/пикселей на дюйм.
- **Офсет / Offset printing:** печать через пластины, для больших тиражей.
- **Цифровая печать / Digital printing:** печать без пластин, для малых тиражей.
- **Препресс / Prepress:** допечатная подготовка.
- **Вырубка / Die-cut:** вырезание формы штампом.
- **Биговка / Scoring:** линия сгиба.
- **Тиснение / Embossing:** рельефное изображение.
- **Конгрев / Blind embossing:** рельеф без краски.
- **Фольгирование / Foil stamping:** нанесение металлизированной плёнки.

## Цифровой дизайн
- **UI/UX:** пользовательский интерфейс/опыт.
- **Дизайн-система / Design system:** набор компонентов, правил, токенов.
- **Токены / Design tokens:** именованные значения решений.
- **Адаптивность / Responsive:** подстройка под размер экрана.
- **Фавикон / Favicon:** иконка сайта.
- **Мокап / Mockup:** изображение, показывающее дизайн на реальном объекте.
- **Прототип / Prototype:** интерактивная модель.

## Процесс
- **Бриф / Brief:** задание на работу.
- **Моудборд / Moodboard:** коллаж настроения и стиля.
- **Скетч / Sketch:** набросок.
- **Концепция / Concept:** идея и её реализация.
- **Референс / Reference:** образец для вдохновения.
- **Хендофф / Handoff:** передача файлов и спецификаций.
